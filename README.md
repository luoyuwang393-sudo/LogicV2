# LogicV2 — USB 逻辑分析仪

基于 CY7C68013A 的 8 路 USB 逻辑分析仪硬件项目，采用嘉立创 EDA 专业版完成原理图与 PCB 设计。

## 硬件组成

| 模块 | 主要器件与设计 |
| --- | --- |
| 主控 | CY7C68013A-56LTXC，配套晶振、复位与去耦电路 |
| 采集输入 | 8 路数字信号输入，74HC245 缓冲、串联排阻与肖特基钳位电路 |
| 存储 | M24C02 EEPROM，通过 I²C 连接主控 |
| 电源 | USB 供电，AMS1117-3.3 稳压与滤波去耦 |
| USB 接口 | USB Type-C 接口，数据线配有 SRV05-4 ESD 保护 |

## 项目工作

独立完成器件选型、原理图设计、PCB 布局布线、打板焊接、固件烧录及实物调试。设计涉及主控最小系统、输入前端、USB 通信及供电保护，并处理 USB、时钟和采集信号走线。

## 文件说明

- `ProPrj_LogicV2_2025-08-26.epro`：嘉立创 EDA 专业版工程文件，包含原理图、PCB、符号及封装数据。
- `.gitattributes`：将 EDA 工程按二进制文件处理。

## 查看工程

下载 `.epro` 文件后，在嘉立创 EDA 专业版中使用工程导入功能打开，查看原理图及 PCB。GitHub 页面无法直接预览该格式。

本仓库提供硬件工程；不包含上位机安装程序、USB 驱动或固件源码。采样率、输入耐压与测试结果以实际硬件及所使用固件的验证结果为准。
